Why teams use Session Replay

Session replay reconstructs what users did in the browser: navigation, clicks, typing, scroll, and DOM mutations. Pair it with RUM vitals and traces to jump from a slow page or JS error into the exact user journey that produced it.

This demo intentionally includes enough UI surface area — filters, forms, a modal, and a tall page — so a capture run produces a richer rrweb event stream than a one-button smoke test.
